BPMN Flow — online BPMN 2.0 editor and process analyzer

BPMN Flow opens, edits, analyzes and exports standard BPMN 2.0 XML directly in your browser. It is free, needs no install or account, and keeps your files on your device. Content the editor does not understand is preserved, and files it cannot round-trip safely open read-only instead of being silently changed.

Features

  • Model with every BPMN event, task and gateway type, sub-processes, boundary events, data objects and annotations
  • Pools, lanes, message flows and collaborations
  • Automatic layout with orthogonal connection routing
  • Process analysis: unreachable or isolated nodes, dead ends, missing end paths, gateway issues, loops and complexity
  • Time and cost estimates from your own task data
  • Verified BPMN 2.0 XML export, compatibility report and browser autosave
